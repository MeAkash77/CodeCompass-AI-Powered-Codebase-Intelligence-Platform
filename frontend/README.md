# Frontend

The Frontend provides an interactive chat interface for code-compass.
It connects to the backend to display LLM answers with citations.

---

## 🧠 Tech Stack

| Component     | Tech                |
| ------------- | ------------------- |
| Framework     | React + Vite        |
| Language      | TypeScript          |
| UI            | Minimal chat layout |
| Communication | REST API + Axios    |

---

## 🚀 Setup
### 1. Environment

Create `.env` file using `.env.example`.

### 2. Start Frontend
```bash
npm install
npm run dev
```

Runs on http://localhost:3001

Backend runs at http://localhost:8000
